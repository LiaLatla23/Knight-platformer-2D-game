# Godot 2D Platformer — Learning Project

## About the Project
This is my second project built while learning Godot. I completed it in one day to reinforce concepts from my previous tutorial and test how much I could remember and implement independently.

Compared to my first attempt, I understood the concepts much faster, encountered fewer unfamiliar concepts, and was able to follow the development process with fewer difficulties.

The goal was not to create a polished game, but to strengthen my understanding of Godot's fundamentals through hands-on practice.

## What I Learned
- Reinforced fundamental Godot concepts.
- Improved my understanding of game logic and node interactions.
- Practiced implementing mechanics while following a tutorial.
- Identified concepts I already understood and areas I still need to practice.

## Tutorial
[How to make a Video Game in Godot — Brackeys](https://youtu.be/LOhfqjmasi0)

This tutorial was particularly helpful for reinforcing concepts and understanding how the different parts of a 2D platformer work together.

## Project Status
Completed as a learning exercise. Further improvements are possible, but polishing the game was outside the scope of this project.
